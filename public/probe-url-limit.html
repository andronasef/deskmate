DeskMate — URL request-line limit probe

This page empirically measures how long a query string your host accepts before rejecting the request (414 / 431 / proxy error). Click each length below. If the page loads with accepted: N bytes, the host accepted that payload. If the browser shows an error page, the host rejected it at or below that length.

DeskMate's display-URL transport caps compressed configs at 4096 bytes (URL_CONFIG_CAP). Record the largest accepted length in 02-03-FINDINGS.md.
