# Milestone v1.0: milestone

**Status:** ✅ SHIPPED 2026-08-16
**Phases:** 1-5
**Total Plans:** 13

## Overview

DeskMate v1.0 — turn any idle screen into a customizable, sandboxed smart dashboard. A static React + Vite app: validated `DashboardConfig` contract (one schema, three transports: localStorage / JSON export-import / `?config=` display URL), a responsive multi-widget grid, the native widget set (Clock, Pomodoro, GitHub Pulse), a sandboxed BYOW ecosystem (srcdoc iframes, `allow-scripts` only, source+nonce postMessage bridge), and an always-on kiosk layer (wake lock, fullscreen, single-widget mobile mode, status indicators, PWA). Persists locally; runs fully client-side; 118 tests green.

## Phases

### Phase 1: Scaffold & Config Core

**Goal**: Users have a static app that boots from a single validated `DashboardConfig` contract and never breaks on bad stored data — the foundation for "one schema, three transports".
**Depends on**: Nothing (first phase)
**Plans**: 2 plans

Plans:

- [x] 01-01: Vite 8 + React 19 + TS 6.0.3 scaffold, lint/type toolchain, dark shell
- [x] 01-02: Config core — zod DashboardConfig, zustand store, versioned storage with validate→migrate→defaults + raw backup (CFG-05)

### Phase 2: Grid, Persistence & Config Transports

**Goal**: Users can edit a responsive multi-widget grid and move their exact configuration across reloads, files, and devices via one validated config — the Core Value working end-to-end.
**Depends on**: Phase 1
**Plans**: 3 plans

Plans:

- [x] 02-01: DashboardGrid + WidgetFrame (RGL v2 hooks, mounted-gated width, edit-mode gating, atomic store actions, responsive breakpoints, seeded default layout)
- [x] 02-02: Transports — debounced localStorage, JSON export/import with backup-before-replace, `?config=` URL codec (lz-string, 4 KB cap, sanitize-on-decode), layout sanitization
- [x] 02-03: URL request-line limit probe (empirically measured ~16 KB dev boundary; cap confirmed safe 4× under)

### Phase 3: Native Widgets

**Goal**: Users get the table-stakes widget set — Clock, Pomodoro, and GitHub Pulse — rendered through a single widget registry/renderer contract with themes and failure-tolerant live data.
**Depends on**: Phase 2
**Plans**: 3 plans

## Milestone Summary

**Decisions (key):** one schema / three transports; sandboxed iframes (never Shadow DOM) with `allow-scripts` only; zustand single store (config + kiosk slices); widget registry as the single render contract (native + custom); theme = minimal `{ accent }` with CSS-variable bridge; URL cap 4 KB with file fallback; backoff ≥3 min for the GitHub budget.

**Issues found & fixed:** create-vite template pitfalls (oxlint/vanilla-ts); jsdom File.text + matchMedia + ResizeObserver gaps; zustand v5 persist async hydration + wire format; RGL v2 layout-mutation/feedback-loop guards; srcdoc all-`</` over-escaping; module-state leaks across tests (backoff/status/reset helpers); CodeMirror onChange driving in jsdom; `useSyncExternalStore` immutable-snapshot contract.

**Tech debt (documented, non-blocking):** layout w/h bounds deferred to grid phase; clock accent-seconds cosmetic; session-scoped GitHub backoff; srcdoc base-URL cookie-request residual (future iframe `csp`); post-deploy verification items (24h soak, deploy-host URL probe).
