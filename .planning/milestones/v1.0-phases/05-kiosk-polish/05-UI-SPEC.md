> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase 5 scope:** Kiosk surfaces — fullscreen toggle, single-widget mobile view, status footer, wake-lock/fullscreen states, PWA chrome. Design system inherited from prior contracts.

---

## Spacing Scale

Inherited. New usages:
- Status footer: 32px bar, `--space-md` horizontal padding, `--space-sm` chip gaps
- Fullscreen toggle: 32px icon-button (matches toolbar)
- Single-widget view: full-bleed (no padding), dots indicator 8px, `--space-md` between dots
- Soak debug panel: fixed right-bottom, `--space-md` padding, 260px width

---

## Typography

Inherited roles. New usages:
- Status chips: Label (12px/400) muted; failure chip uses `--destructive`-tinted text
- Single-widget dots: no text
- Debug panel: Label (12px) monospace values

---

## Color

Inherited roles. New bindings (no new hex):
- Fullscreen toggle active: `--accent`; inactive muted
- Status footer: `--surface` bar, `--border` top hairline
- Failure chip: `--destructive` icon/text; stale chip: `--text-muted` + warning icon; wake-lock chip: `--accent` (awake) / muted (unavailable)
- Single-widget view background: `--background`; dots: `--border` (inactive) / `--accent` (active)

**Accent reserved for** (extends prior lists): fullscreen-active toggle, wake-lock "Screen awake" chip, active dot, focus rings.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Fullscreen toggle | title **"Enter fullscreen"** / **"Exit fullscreen"** (aria-label same) |
| Status chips | **"N widget(s) failed to load"** / **"GitHub data stale"** / **"Screen awake"** / **"Screen awake unavailable"** |
| Wake-lock fallback | **"Screen awake unavailable"** — shown when unsupported/rejected (KIOSK-02, calm, non-blocking) |
| Single-widget view | No copy — pure widget + dots (kiosk-clean) |
| Soak panel | **"Kiosk diagnostics"** header; rows: frame time, memory, wake lock, chime ready, last refresh |
| Soak manual items | Documented in `.planning` (chime on fresh profile; 2-widget rate-limit simulator) |

Copy tone: calm, zero-config, kiosk-quiet (inherited).

## UI Considerations

Applicable state considerations resolved: 7 covered, 1 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | single-widget view with zero widgets | ✅ covered | Falls back to the grid empty state (cannot select from nothing) |
| error | wake lock unsupported/rejected | ✅ covered | "Screen awake unavailable" chip; app fully functional (KIOSK-02) |
| error | fullscreen request rejected | ✅ covered | Info toast; toggle returns to idle |
| one-many | many widgets in single-widget view | ✅ covered | Arrows + dots cycle through all; first widget default (D-5.06) |
| long-text | status chips overflow on narrow screens | 🧪 backstop | Chips ellipsis-truncate; footer scrolls horizontally if needed — held-out visual test |
| hidden | tab hidden during kiosk | ✅ covered | Wake-lock re-acquires on visibilitychange (D-5.01); chips reflect state |
| stable | 24h soak stability | ✅ covered | Instrumentation panel + documented procedure (D-5.15); budgets already cap frames |
| reduced-motion | kiosk transitions | ✅ covered | No animations beyond RGL's existing 200ms transitions (already minimal) |
