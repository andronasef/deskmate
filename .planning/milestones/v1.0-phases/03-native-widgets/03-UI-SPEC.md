# Phase 3 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase 3 scope:** The three native widget bodies (Clock, Pomodoro, GitHub Pulse) rendered through the registry into WidgetFrame, the per-widget settings popover, and the theme bridge (accent → `--widget-accent`). Design system inherited from Phase 1/2 contracts.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — CSS Modules + CSS custom properties |
| Preset | not applicable |
| Component library | none — custom primitives only |
| Icon library | lucide-react (inherited; + settings gear, play, pause, rotate-ccw, star, git-branch, flame) |
| Font | Inter Variable — self-hosted (inherited) |

### Theme Bridge (D-3.06)

WidgetFrame sets `--widget-accent: var(--accent)` from `config.theme.accent` (the stored token's value flows in via the `accent` prop). Widget bodies bind exclusively to `var(--widget-accent)` for brand accents — never hardcoded hex. All other tokens inherited from `:root`.

---

## Spacing Scale

Inherited (xs 4 → 3xl 64). New usages:
- Widget internal padding: `--space-md` (16px), centered layout
- Settings popover: `--space-md` padding, 260px width, `--space-sm` control gaps
- GitHub metric row: `--space-sm` gap between icon + value, `--space-lg` between metric groups
- Pomodoro controls: 40px buttons (`--space-xl` + 8px), 8px radius

---

## Typography

Inherited roles. New usages:
- **Clock time:** Display (28px/600) large; fontSize setting scales 28 → 40 → 56px (small/med/large, D-3.07)
- **Clock date:** Label (14px/400) muted
- **Pomodoro countdown:** Display (28px/600) at 40px+ (large readable countdown per WID-02), tabular-nums
- **GitHub repo name:** Label (14px/600); metric values: Body (16px/600); footer status: Label (12px) muted
- **Settings popover label/controls:** Label (14px/400), inputs 14px

---

## Color

Inherited roles. New bindings (no new hex):
- Clock time: `--text-primary`; accent seconds digits when `showSeconds`
- Pomodoro running: countdown `--widget-accent`; paused: `--text-primary`; zero/alert: `--destructive`
- GitHub stars: `--widget-accent` icon; issues: `--text-primary` icon; streak: `--widget-accent` flame
- Status footer: `--text-muted`; rate-limit warning: `--destructive`-tinted text (destructive used for warnings only)
- Settings gear hover: `--accent`; popover focus ring: `--accent`

**Accent reserved for** (extends prior lists):
1. `:focus-visible` rings
2. Pomodoro running countdown
3. GitHub stars/streak icons
4. Settings gear hover
5. Clock accent seconds (when enabled)

## Copywriting Contract

| Element | Copy |
|---------|------|
| Clock date | Locale-formatted date via `Intl.DateTimeFormat` (e.g. "Saturday, August 16") — no hardcoded strings |
| Pomodoro controls | **"Start"** / **"Pause"** / **"Reset"** — accessible labels + tooltips |
| Pomodoro done | **"Time's up!"** (accent text) + chime |
| GitHub error (no data yet) | **"No data yet"** + status line |
| GitHub rate limited | **"Rate limited — showing cached data"** (muted/destructive-tinted) |
| GitHub stale | **"Updated HH:MM"** (muted, always) |
| Settings popover | **"Settings"** header; fields: Clock — Show seconds / 24-hour / Font size; Pomodoro — Minutes; GitHub — Repos (comma-separated owner/repo) + **"Save"** / **"Cancel"** |
| Unknown widget type | **"Unknown widget type"** (fallback body, muted) |
| Empty repos list | **"No repos configured"** + hint |

Copy tone: calm, zero-config, offline-friendly (inherited).
