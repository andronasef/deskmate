ClockWidget (src/widgets/clock.tsx):
- Props: { widget: WidgetInstance; theme: WidgetTheme } (editMode unused)
- settings: showSeconds (bool, default false), hour12 (bool, default true), fontSize ('small'|'medium'|'large', default 'medium')
- Renders time via Intl.DateTimeFormat(locale, { hour, minute, second?, hour12 }); date via Intl.DateTimeFormat(locale, { weekday:'long', month:'long', day:'numeric' })

- Ticks every second (setInterval, cleaned up on unmount); showSeconds=false still re-renders on minute boundary

PomodoroWidget (src/widgets/pomodoro.tsx):
- Props: { widget: WidgetInstance; theme: WidgetTheme }
- settings: minutes (number 1-120, default 25)
- State: secondsLeft, running, phase ('focus'|'done')
- Start: creates AudioContext (unlocked by the gesture — the click handler), runs countdown via interval; Pause stops; Reset returns to minutes
- At 0:00: chime (Web Audio oscillator — short two-tone), phase 'done' → "Time's up!" + destructive accent (UI-SPEC)
- Countdown renders MM:SS tabular-nums, accent when running, text-primary when paused (UI-SPEC)
- Interval cleaned up on unmount (no zombie timers)
</interfaces>
