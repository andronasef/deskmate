```typescript
export interface WidgetCode { html: string; css: string; js: string }
export function buildSrcdoc(code: WidgetCode, nonce: string, api: object): string
  // Full HTML doc; bootstrap <script> injects window.__deskmateNonce = '...' and window.deskmate = api-shim;
  // embeds user css (in <style>), user html (in <body>), user js (in a final <script>);
  // every embedded string is </script>-escaped (split on '</script>' → '<\\/script>');
  // bootstrap posts {type:'deskmate:ready', nonce} on load (targetOrigin '*');
  // exposes window.deskmate = { theme, size, config } receive-updates via postMessage listener.

```

bridge.ts:
```typescript
export class SandboxBridge {
  constructor(iframe: HTMLIFrameElement, nonce: string, onApi: (api: unknown) => void)
  attach(): void      // window.addEventListener('message', handler)
  destroy(): void    // remove listener + invalidate nonce
  // handler: if e.source !== iframe.contentWindow → ignore; parse e.data; if type === READY and data.nonce === this.nonce → post API {type:'deskmate:api', nonce, api} (targetOrigin '*'); if UPDATE → same validation → onApi
}
export function createSandboxBridge(iframe, nonce, onApi): SandboxBridge
```

IframeWidgetRenderer.tsx:
- Props: { widget, theme, editMode } — renders the sandboxed iframe (sandbox=SANDBOX_TOKENS, referrerpolicy='no-referrer', srcdoc=buildSrcdoc(...)) with three states: loading ("Loading widget…"), ready (iframe visible), crashed ("Widget failed to load" + hint) after READY_TIMEOUT_MS.
- On ready: bridge delivers API (theme accent, container size via ResizeObserver, config snapshot) and pushes on resize/theme change (D-4.06).
- Teardown (BYOW-05): on unmount → bridge.destroy() (removes listener + invalidates nonce) + iframe removed with the component. No timers leak (timeout cleared).
