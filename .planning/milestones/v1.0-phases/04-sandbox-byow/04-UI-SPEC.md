# Phase 4 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase 4 scope:** The BYOW editor drawer (CodeMirror HTML/CSS/JS tabs + live preview), custom-widget sandbox states (loading/crashed/ready), and the "Add Custom Widget" flow. Design system inherited from prior contracts. Security surfaces (iframe attributes, nonce bridge) are specified in 04-CONTEXT/PITFALLS — this contract covers what the USER sees.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — CSS Modules + CSS custom properties |
| Preset | not applicable |
| Component library | none — custom primitives only |
| Icon library | lucide-react (inherited; + code, eye, file-code, terminal) |
| Font | Inter Variable (inherited); CodeMirror editor uses monospace stack (`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`) |

---

## Spacing Scale

Inherited. New usages:
- Editor drawer: fixed right panel, 480px wide (collapsed to full-width ≤ sm breakpoint), `--space-lg` padding
- Drawer tabs: 32px tab bar, `--space-md` gap
- Sandbox fallback body: centered, `--space-md` padding
- Preview header strip: 32px, `--space-sm` padding, muted

---

## Typography

Inherited roles. New usages:
- Drawer title "Custom Widget": Heading (20px/600)
- Tab labels + Save/Cancel: Label (14px/400)
- Editor code: 13px monospace, 1.5 line height
- Sandbox fallback: Body (16px/400) muted + Label (14px) hint
- Sandbox "live preview" badge: Label (12px) accent

---

## Color

Inherited roles. New bindings (no new hex):
- Editor tabs active: `--accent` underline + text; inactive: `--text-muted`
- CodeMirror chrome: `--surface-raised` background, `--border` gutters
- Sandbox fallback: `--surface` body, `--text-muted` text, dashed `--border` outline
- Live-preview badge: `--widget-accent`
- Drawer backdrop: `rgba(0,0,0,0.4)` scrim
- Budget-block toast: standard info toast (no new color)

**Accent reserved for** (extends prior lists): focus rings, active editor tab, live-preview badge, Save button.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Add custom widget | **"Add Custom Widget"** — edit-mode catalog entry (name: "Custom Widget", desc: "Bring your own HTML, CSS, and JS") |
| Drawer title | **"Custom Widget"** |
| Tabs | **"HTML" / "CSS" / "JS"** |
| Save / Cancel | **"Save"** / **"Cancel"** |
| Unsaved changes | **"Discard unsaved changes?"** (confirm dialog on Cancel with edits) |
| Sandbox loading | **"Loading widget…"** (muted, shown until ready handshake) |
| Sandbox crashed | **"Widget failed to load"** + hint **"It may have crashed or timed out."** |
| Budget blocked (mobile) | **"Widget limit reached (8 on this device)."** |
| Budget blocked (desktop) | **"Widget limit reached (20 on this device)."** |
| Code size cap | **"Widget code exceeds the size limit (100 KB)."** |
| Unknown widget type | Inherited: **"Unknown widget type"** |
| Empty code template | `<!-- hello! -->` + `body { color: var(--deskmate-accent) }` + `console.log("hello from DeskMate")` — the DeskMate API (`window.deskmate`) is documented in an HTML comment |

Copy tone: calm, zero-config, developer-friendly (the only power-user surface in v1).

## UI Considerations

Applicable state considerations resolved: 8 covered, 2 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| loading | sandbox frame (before ready) | ✅ covered | "Loading widget…" until the nonce-validated ready handshake (3 s timeout → crashed state) |
| error | sandbox crash/timeout | ✅ covered | "Widget failed to load" + hint; app + other widgets unaffected (D-4.15) |
| empty | editor with blank template | ✅ covered | Template comment + example code seeded on first add |
| unsaved | drawer Cancel with edits | ✅ covered | "Discard unsaved changes?" confirm (BYOW-02 flows protected) |
| overflow | many custom widgets | ✅ covered | Budget block with per-device toasts (D-4.13); lazy mounting keeps offscreen frames cheap (D-4.14) |
| long-text | user widget code | 🧪 backstop | CodeMirror scrolls (no max-height limit); 100 KB cap enforced — held-out visual test |
| unknown | custom widget with invalid code | ✅ covered | Sandbox isolates failures — fallback body, never the app |
| one-many | one custom widget in multiple grid cells | ✅ covered | Each grid item mounts its own iframe with its own nonce (budget counts frames) |
| reduced-motion | none applicable | — | — |
| mobile | editor drawer width | ✅ covered | 480px panel collapses to full-width below the sm breakpoint |
