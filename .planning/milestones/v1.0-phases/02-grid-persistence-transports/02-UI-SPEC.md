# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase 2 scope:** The multi-widget grid (react-grid-layout v2) with edit mode, widget chrome, add-widget flow, and the three config transports (persistence, JSON export/import, display URL). Design system (tokens, typography, spacing, color roles) is INHERITED from Phase 1's approved contract — this spec adds only the new surfaces and their interaction states. All new UI binds to the existing `:root` tokens; no new tokens unless explicitly declared.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — CSS Modules + CSS custom properties (locked by STACK.md) |
| Preset | not applicable |
| Component library | none — custom primitives only (IconButton, Popover, Toast, WidgetFrame chrome) |
| Icon library | lucide-react 1.29.x (added this phase: settings, plus, trash, download, upload, link, x, grip) |
| Font | Inter Variable — self-hosted via `@fontsource-variable/inter` (inherited from Phase 1) |

### Grid Library Styling

react-grid-layout v2 CSS (`react-grid-layout/css/styles.css`) + `react-resizable/css/styles.css` imported at app level, then overridden via CSS Modules to bind to DeskMate tokens:
- Placeholder (empty drop cell): 2px dashed `--border`, 8px radius, `--surface` fill at 50% opacity
- Resize handle: `--accent` on hover (2px), otherwise invisible in display mode
- Drag ghost: elevated `--surface-raised` with 8px shadow (`rgba(0,0,0,0.4)`), 1px `--border`

---

## Spacing Scale

Inherited from Phase 1 (xs 4 → 3xl 64, all multiples of 4). New usages:
- Grid gap: `--space-md` (16px) between widgets
- Grid padding: `--space-lg` (24px) page gutter
- Widget chrome buttons: 32px touch targets (`--space-xl`), 8px radius
- Popover: `--space-md` padding, `--space-lg` width (240px)
- Toast: `--space-md` padding, `--space-lg` radius (8px), bottom-center, `--space-xl` from bottom

---

## Typography

Inherited from Phase 1 (Body 16/400/1.5, Label 14/400/1.5, Heading 20/600/1.2, Display 28/600/1.2). New usages:
- Header toolbar buttons: Label (14px/400), `--text-muted`, hover `--text-primary`
- Widget title in chrome: Label (14px/400) `--text-muted`
- Shared-config banner: Label (14px/400) `--text-primary` on `--accent`-tinted surface
- Toast body: Body (16px/400) `--text-primary`

---

## Color

Inherited from Phase 1 roles. New bindings (no new hex values):
- Edit-mode toggle (active): `--accent` text + 1px `--accent` border; inactive: `--text-muted` + `--border`
- Add-widget popover row hover: `--surface-raised` background
- Remove-widget button: `--text-muted`, hover `--destructive`
- Shared-config banner background: `--surface-raised` with 1px `--accent` left border (3px)
- Toast success: `--accent` icon; error: `--destructive` icon
- Grid placeholder (empty cell): dashed `--border`

**Accent reserved for** (extends Phase 1 list):
1. `:focus-visible` ring (2px, 2px offset) on all interactive elements
2. Active edit-mode toggle
3. RGL resize-handle hover
4. Import/export/URL action icons on hover
5. Shared-config banner accent border

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (edit mode) | **"Add Widget"** — header button, opens the widget catalog popover |
| Edit-mode toggle | **"Edit"** (off → on), **"Done"** (on → off) — same button, toggled label |
| Widget remove | **"Remove widget"** — icon button (trash), title attribute; no confirmation in v1 (removal is undoable via re-add; config backup exists) |
| Empty grid state | **"Your dashboard is empty"** / **"Add a widget to get started."** (shown only when zero widgets AND edit mode) |
| Import error toast | **"Import failed: {reason} — your current dashboard was not changed."** |
| Import success toast | **"Dashboard imported."** |
| Export | **"Export config"** — header action, downloads `deskmate-config.json` |
| Shared config banner | **"Viewing a shared dashboard"** — body: **"Save it to your dashboard or exit to keep yours."** with actions **"Save to my dashboard"** / **"Exit"** |
| URL too large fallback | **"This config is too large for a link — export it as a file instead."** (info toast) |
| Error state | Silent recovery inherited (console warning only, CFG-05). Import/URL decode failures surface via toasts above — never a blank screen. |

Copy tone: calm, zero-config, offline-friendly (inherited).

## UI Considerations

Applicable state considerations resolved: 6 covered, 1 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | grid (zero widgets) | ✅ covered | "Your dashboard is empty / Add a widget to get started." renders only in edit mode; display mode shows nothing |
| empty | widget catalog (no types) | ✅ covered | Catalog derives from defaultConfig seed — always ≥3 types in v1; impossible empty state documented as assumption |
| error | import invalid JSON | ✅ covered | "Import failed: {reason} — your current dashboard was not changed." + current config untouched (D-2.10) |
| error | URL decode/validate failure | ✅ covered | Invalid `?config=` is ignored with a console warning + info toast; stored config renders instead |
| populated | grid with widgets | ✅ covered | Widgets render from validated config; RGL layout applies per breakpoint |
| overflow | >50 widgets (schema cap) | ✅ covered | zod `.max(50)` rejects at validation; add-widget flow blocked with info toast at cap |
| long-text | widget titles in chrome | 🧪 backstop | Titles are truncated (ellipsis, max-width 120px); held-out visual test for Phase 3 registry UI |

## Interaction States

| Surface | Display mode | Edit mode |
|---------|--------------|-----------|
| Grid | Read-only render; no handles, no chrome | RGL drag/resize active; per-widget remove button top-right; drag ghost |
| Header | Wordmark + Edit toggle + Export + Import + URL share | Same toolbar + "Add Widget" button; Edit toggle reads "Done" |
| Widget chrome | Hidden | Visible on hover (or always in edit mode on touch): remove (trash) top-right |
| Add-widget popover | n/a | Opens on "Add Widget"; lists 3 types with name + 1-line description; click adds at first free slot |
| Shared-config banner | Rendered when `?config=` active | Same + "Save to my dashboard" replaces stored config (with backup) |

Touch targets: all chrome buttons ≥ 32px (44px recommended on touch; Phase 5 revisit).
