<objective>
Empirically verify the deploy host's request-line limit (the STATE.md research flag: "deploy-host request-line limit unknown — probe with a long-query-param page (plan 02-03) before finalizing the URL size cap"). Ship a probe page that loads with progressively longer query strings and reports the largest payload the host accepted. Record findings and confirm (or adjust) `URL_CONFIG_CAP` (default 4096 from plan 02-02).

Purpose: The `?config=` transport (CFG-04) depends on the host accepting the encoded payload in the URL. nginx defaults to 8 KB and CDNs vary; a hard cap of ~4 KB is the safe default, but the actual deploy host limit must be measured so the cap is grounded in fact, not assumption.

Output: `public/probe-url-limit.html` (static, no build step) + `02-03-FINDINGS.md`.
</objective>
