04-01-FINDINGS.md must resolve, with evidence:
1. **Opaque origin**: with `sandbox="allow-scripts"` (no allow-same-origin) + srcdoc, the frame has an opaque origin → parent receives `event.origin === "null"`; `targetOrigin` must be `"*"` (no origin to target). CONFIRM + document.
2. **event.source identity**: parent can reliably identify the sender as `event.source === iframe.contentWindow` (the only safe identity check). CONFIRM.
3. **srcdoc escaping**: any `</script>` sequence inside injected bootstrap/user code can terminate the bootstrap script — document the exact escaping rule (split `</script>` → `<\/script>` or `\u003C/script>` in JS strings; escape in HTML comments too).
4. **srcdoc base-URL trap** (PITFALLS): srcdoc uses the embedding doc's URL as base → relative URLs inside the widget resolve against the host → do NOT give allow-same-origin, and advise widgets to use absolute URLs. CONFIRM + document the mitigation.
5. **Spoofing surface**: an attacker page can't get a message accepted because (a) it's not our iframe's contentWindow, and (b) it doesn't know the per-widget nonce. Document why source+nonce beats origin.
</interfaces>
